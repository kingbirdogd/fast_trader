1) Underlying Warrant List
cmd=uwarrantlist

parameters:
issuer : Issuer code  (CS, MB, SG ....)
ucode : underlying code

response:

action=uwarrantlist
ucode=[0,9]{1,5}   unsigned int
codes=12345, 23456    (String Type)
issuer=[CS, MB, SG .....]
result=[SUCCESS,FAIL]
