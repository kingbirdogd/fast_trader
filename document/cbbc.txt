
#Command

1) SET

set|wtype|symbol|warrant code|issuer size|buy quantity|spread|ref

wtype = bull or bear
warrant code = [0-9]{5}
symbol = HSIH0    (HSI 3ды )
issuer size = 10000000  = 10M
buy quantity = 10000   (10000)
spread = 0.001

2) PAUSE
pause|warrant code|ref

json["result"] = "SUCCESS";

6) PARAM
param|warrant code|type|value|ref

type: 
In Out Range | INOUT
Win Tick | WINTICK
In Lvl Range | INLVL
Stop Lost | STOPLOST
Point Range | PTRANGE

value:
integer value

response
json["action"] = "command param"
json["result"] = "SUCCESS";
