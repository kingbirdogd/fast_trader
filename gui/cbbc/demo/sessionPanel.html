Session Panel 

    

    

    
    

    



  
    

      1.0 密码层
      
        参数：Username + Password 

        返回：安全认证Token（每次登入都不同的安全认证） 

      		
    

    

      2.0 认证层Sessions
      
        
    
          
  •  token - 安全认证 
    • 
          
  •  userId - 用户ID 
    • 
          
  •  origin - 登入来源（cbbc / hts） 
    • 
          
  •  priority - 优先级（First in last out） 
    • 
          
  •  loginTime 登入时间 
    • 
        

      		
    

    

      3.0 通信层Websocket
      
        参数：Websocket（必须拥有安全认证Token才能访问） 

        返回：响应Msg
      		
    

    

      4.0 应用层
      
        刷新：删除WS通信层=>重新建立WS

        登出：删除WS通信层=>删除Sessions认证层

        （最大的priority才能访问&操作WS通信层）
